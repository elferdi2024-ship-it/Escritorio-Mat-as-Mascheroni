# 🎨 Design System Visual — Lo que faltaba

Tenés razón en preguntar. **Honestamente: no.** Entregué arquitectura, código y lógica de negocio, pero **no desarrollé un design brief visual detallado**. El prompt a Antigravity menciona el skill `ui-ux-pro-max` pero sin una especificación concreta de cómo debe verse cada pantalla.

Te lo resuelvo ahora con un **Design System completo tipo agencia** que podés:
- Mostrarle al cliente como propuesta visual
- Agregar al prompt de Antigravity
- Usar como referencia para diseñar en Figma si querés

---

## 🎭 1. Concepto Visual: "Editorial Rural Premium"

**No es** el típico sitio verde con tractores clip-art.
**Sí es** una mezcla entre *catálogo de subastas Sotheby's* + *revista Country Living* + *UI de fintech moderna*.

### Referencias visuales (moodboard mental)

| Referencia | Qué tomamos |
|---|---|
| **Ritchie Bros** | Densidad de información, cards de maquinaria, seriedad |
| **Bring a Trailer** | Fotografía hero, tipografía editorial, feeling de "subasta premium" |
| **Stripe Press** | Minimalismo tipográfico, mucho espacio en blanco, detalles finos |
| **Country Living Magazine** | Paleta tierra/verde trigo, feeling rural pero elegante |
| **Linear.app** | Micro-interacciones, glassmorphism sutil, dark accents |

### Personalidad de marca
- **Confiable** (como un banco rural)
- **Premium** (como una subasta de arte)
- **Moderna** (como una fintech)
- **Cercana** (como el almacén del pueblo)

## 🎬 5. Micro-interacciones (especificación)

| Acción | Animación |
|---|---|
| Hover en card | `translateY(-4px)` + `shadow-card` + `scale(1.02)` en imagen, 300ms `ease-smooth` |
| Click en "Pujar" | `scale(0.95)` 150ms + `ripple` effect |
| Puja exitosa | Toast slide-in + sonido agudo + vibración mobile (`navigator.vibrate(100)`) |
| Ser superado | Toast rojo + sonido grave + shake sutil del panel (200ms) |
| Prórroga | Banner dorado con `shine` gradient animado 2s + sonido fanfarria corto |
| Countdown < 1 min | Pulse + color rojo + número de segundos con `tabular-nums` |
| Contador de pujas | Número hace "flip" vertical (estilo reloj aeropuerto) |
| Scroll en home | Navbar cambia de transparente a glass blur al pasar 50px |
| Lightbox abrir | Fade 200ms + scale 0.95→1 con spring |
| Cambio de tab álbum | Grid hace `stagger` animation (cada card 50ms delay) |

| `sm` | ≥ 640px | Grid 2 cols, hero texto más grande |

| `lg` | ≥ 1024px | Grid 4 cols, layout completo |
| `xl` | ≥ 1280px | Max-width 1440px centrado |

**Mobile-first:** diseñar primero xs, luego escalar.

```markdown
# 🎨 ESPECIFICACIÓN VISUAL (DESIGN BRIEF)

Seguí estrictamente este design brief. NO improvises estéticamente.

## Referencia conceptual
"Editorial Rural Premium" — mezcla de catálogo Sotheby's + revista Country Living + UI fintech moderna.
Referencias visuales: Ritchie Bros, Bring a Trailer, Stripe Press, Linear.app.

## Design tokens obligatorios
Usá EXACTAMENTE los tokens del archivo `app/globals.css` especificado en el design brief (paleta forest/wheat/earth/cream en oklch, tipografías Outfit+Inter, radios, sombras HSL, easings).

## Tipografía
- Display: Outfit (H1, H2, títulos, precios, countdown)
- Body: Inter (texto general, labels, inputs)
- Mono: JetBrains Mono (códigos, IDs)
- Todos los números tabulares (precios, timers) con `font-variant-numeric: tabular-nums`

## Wireframes de referencia
Ver sección "Wireframes textuales" — respeta la estructura de cada página:
- Home: Hero 90vh + live ticker + stats bar + álbumes + "cómo funciona" + CTA + footer
- Detalle lote: Grid 2 columnas (60/40) con panel puja sticky en desktop
- Admin login: Card centrada con glass blur
- Admin dashboard: Sidebar + stats grid + tabla

## Micro-interacciones
- Hover cards: translateY(-4px) + shadow-card + scale(1.02) en imagen, 300ms ease-smooth
- Botón CTA: scale(0.95) en active, 150ms
- Toasts: slide-in desde abajo con ease-spring, auto-dismiss 4.5s con progress bar
- Prórroga: banner dorado con shine gradient 2s
- Countdown < 1 min: pulse + rojo + tabular-nums
- Cambio de álbum: stagger animation (50ms delay por card)

## Estados del countdown (CRÍTICO)
- safe (> 10 min): verde forest plano
- warning (1-10 min): amarillo trigo con pulse 1.5s
- critical (< 1 min): rojo con pulse + scale 0.8s
- extended: verde + borde dorado + shine gradient
- closed: gris oscuro, sin animación

## PROHIBIDO
- Placeholders tipo "Lorem ipsum" o "Sample image"
- Imágenes grises genéricas
- Tipografía system-ui por defecto
- Sombras negras (usar HSL earth-950/alpha)
- Bordes hard (usar siempre radius-md o mayor)
- Animaciones de más de 500ms (excepto shines loops)

## Assets
- Hero home: foto de campo uruguayo golden hour con overlay gradiente
- Lotes: fotos reales de maquinaria (Unsplash válido)
- Logo: texto "Remates Agrícolas" en Outfit + isotipo tractor SVG
- Favicon: isotipo en fondo forest

Cada componente debe tener ESTADOS visuales definidos: default, hover, active, focus, disabled, loading, error, success.
```
